# 교실 쾌적도

UNO 고급키트(SZH-EK013)로 교실 온도·습도를 재고, 적정 범위를 벗어나면 빨강 LED 깜박임·부저·LCD 경고를 내는 장치와 웹 대시보드입니다. ISO 9241과 WCAG 2.2를 기준으로 만들고 있습니다.

```
UNO (firmware/PL3) ──USB 115200 JSON──▶ bridge/app.py ──HTTP·WebSocket──▶ dashboard/ (브라우저)
```

## 폴더

| 폴더 | 내용 |
|---|---|
| `firmware/PL3/` | UNO 펌웨어. 핀은 `pins.h`, 명령·필드는 `README.md` |
| `bridge/` | PC 연결 프로그램(FastAPI + pyserial). `--simulate`로 가상 보드 사용 |
| `dashboard/` | 웹 화면. `index.html`(대시보드), `wiring.html`(빵판 배선도) |
| `planning/` | 처음 기획 페이지(서비스 안 4가지). 회로도는 옛 PL2 기준 |

## VS Code에서 이어서 하기

1. VS Code에서 **폴더 열기**로 이 폴더(`웹대시보드`)를 엽니다. 추천 확장(Python, Python Debugger, Claude Code)을 설치하라는 알림이 뜨면 설치합니다.
2. 다른 PC라면 `Ctrl+Shift+P` → **Tasks: Run Task** → **브리지 가상환경 다시 만들기**를 한 번 실행합니다.
3. **보드 없이 화면 작업**: `Ctrl+Shift+B`(기본 빌드 작업 = 브리지 실행 (시뮬레이션)) → 브라우저에서 http://127.0.0.1:8000
   - 디버거로 보려면 `Ctrl+Shift+D` → **브리지(시뮬레이션) + 대시보드** → `F5`
4. **실제 보드**: 작업 실행 → **보드 포트 목록** → **펌웨어 업로드 (PL3)** → **브리지 실행 (실제 보드)**. COM 포트를 물어봅니다.
5. 바꾼 뒤 확인: 브리지를 켠 상태에서 **브리지 스모크 테스트** 작업.

필요한 것: Python 3.12 이상(지금은 3.14로 시험), `arduino-cli`와 `arduino:avr` 코어, 라이브러리 DHT sensor library 1.4.7 / Adafruit Unified Sensor 1.1.15 / hd44780 1.3.2.

## 지켜야 할 규칙 (강의 자료 기준)

- 보유품은 고급키트뿐. 외부 5V 전원이 없어 모터는 쓰지 않습니다. 한 번에 회로 하나만 꽂습니다.
- 시리얼은 115200, 줄 끝 LF, 응답은 JSON 한 줄. D0/D1은 비웁니다.
- 화면에서 `null`(측정 대기), 실제 0, 연결 끊김을 섞지 않습니다. 3초 넘게 값이 없으면 제어를 막고, 명령을 자동으로 다시 보내지 않습니다.
- `ack`는 "보드가 적용함"이지 "LED가 켜짐을 확인함"이 아닙니다.
- 핀을 바꿀 때는 코드보다 배선표(`firmware/PL3/pins.h`, `dashboard/wiring.js`)를 먼저 바꿉니다.
