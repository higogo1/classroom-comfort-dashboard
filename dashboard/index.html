보드 연결브리지에 연결하는 중

화면 갱신을 멈췄습니다. 데이터는 계속 받고 있으며, 다시 누르면 최신 값으로 바뀝니다.
시뮬레이션 모드입니다. 화면의 숫자는 가상 보드가 만든 값이며 실제 측정값이 아닙니다. 버튼을 눌러도 실제 보드는 움직이지 않습니다.

값을 기다리는 중이에요.

보드에서 첫 상태가 오면 표시됩니다.

판정 규칙

  • 자동 판정: 온도와 습도가 모두 적정 범위 안이면 초록불입니다. 하나라도 벗어나면 빨간불이 깜박이고 부저가 울리며 LCD에 TEMP HIGH 29.0C 같은 문구가 나옵니다.
  • 다시 적정 범위로 돌아와도 3번(약 6초) 연속 적정이어야 초록불로 바뀝니다. 경계에서 깜박임이 반복되지 않게 하기 위해서입니다.
  • 측정 대기는 DHT11이 아직 값을 주지 않았거나 읽기에 실패한 상태입니다. 0°C가 아닙니다. 이때 자동 판정은 두 LED를 모두 끕니다.

명령 결과

  • 보드 적용됨: 보드 프로그램이 명령을 받아 적용했습니다. LED와 부저가 실제로 동작했는지는 직접 확인하세요.
  • 응답 없음: 2초 안에 답이 없었습니다. 적용됐는지 알 수 없으니 상태를 확인한 뒤 다시 보내세요. 자동으로 다시 보내지 않습니다.
  • 값 멈춤: 3초 넘게 새 값이 없으면 제어를 막습니다. 이때 LED나 부저가 꺼졌다고 가정하지 마세요.

연결이 안 될 때

  • Arduino 시리얼 모니터를 닫으세요. 같은 포트를 두 프로그램이 동시에 열 수 없습니다.
  • 브리지 실행 창의 포트 번호가 맞는지 확인하세요 (arduino-cli board list).
  • "보드 회로가 PL2입니다"처럼 다른 회로 이름이 보이면 PL3 펌웨어를 업로드하세요.
